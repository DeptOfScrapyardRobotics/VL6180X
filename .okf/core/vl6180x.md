# Role

I2C time-of-flight (+ ambient-light register surface) driver for the ST VL6180X. Extends `GeneralPurposeIO\Circuits\SensorIC` and implements `BootSequence`.[^ic]

# Attributes

```php
#[IntegratedCircuit('I2C')]
#[Pinout(['I2C' => ['driver', 'device', 'slave']])]
```

Pinout is I2C-only. Optional digital pins (`shutdown_pin` / XSHUT, `interrupt_pin`) are constructor / factory arguments — not Pinout keys.[^ic]

# Factories

| Factory | Notes |
|---------|-------|
| `::i2c($device, $adapter, $slave, …knobs…, ?$interrupt_pin, ?$shutdown_pin, $boot_now)` | Builds via `I2C::adapter` → `fromI2CBus` |
| `::fromI2CBus(I2CSlave $i2c, …)` | Already-open slave |

Default slave: `VL6180XI2CAddress::DEFAULT` (`0x29`). Default `boot_now` true on factories (ctor default false).[^ic][^address]

Constructor knobs (int / ALS period pair) inject recommended register values applied in `_boot()` via `loadRecommendedSettings()`.[^internal-api]

# Ranging surface

| Method | Meaning |
|--------|---------|
| `distance(DistanceUnit $unit = MM)` | Single-shot range converted from mm |
| `readRange()` | Raw mm; polls I2C status when `interrupt_pin` is null; returns `-1` on timeout **or** when INT pin is set (unfinished) |
| `startMeasurement()` / `statusReady()` / `statusWait()` / `clearInterrupt()` | Hot-path I2C helpers |
| `close()` | Closes interrupt/shutdown pins (if any) then transport |

Magic properties expose device id, fresh-out-of-reset, and tuning registers; unknown names throw `VL6180XException` (extends `CircuitException`).[^ic][^api][^exception]

# Boot

- Uses `GeneralPurposeIO\Contracts\Circuits\BootScaffolding` + Nab `Splices16Bits` (16-bit opcode address split).[^internal-api]
- `_boot()`: optional XSHUT pulse → confirm model id `0xB4` → proprietary settings **only if** `system_fresh_out_of_reset` → load recommended settings.
- Wire path: `VL6180XCarrierTransport` over `I2CSlave` only.[^transport]

# Units

Implements `Waveforms\Distance\MeasuresDistance`. Units are `Waveforms\Contracts\Sensors\Enums\DistanceUnit` (package-local enum removed). See [Fabricate leftovers](../traps/fabricate-leftovers.md).
